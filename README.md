# Family Hub

Wall-mounted family command center — React app deployed to GitHub Pages.

See [family-hub-project.md](./family-hub-project.md) for full project context, phase status, and to-do list. Read that file first in any new session on this project.

## Development

```
npm install
npm run dev
```

## Build

```
npm run build
```

Deploys automatically to GitHub Pages via GitHub Actions on push to `master`.
